# Smart Expense Tracker 💰

A beginner-friendly Python application designed to manage daily expenses and monthly budgets.

## Features
- Add daily expenses.
- View saved expense records.
- Calculate monthly expenses.
- Set a monthly budget.
- Analyse expenses by category.
- Track remaining budget.

## Technologies Used
- Python
- CSV
- File Handling
- DateTime Module

## How to Run

1. Install Python.
2. Download or clone this repository.
3. Open the project folder in VS Code.
4. Run the following command:

python expense_tracker.py

## Project Objective

The objective of this project is to develop a simple expense management system that helps users monitor their spending habits and manage their monthly budgets.
